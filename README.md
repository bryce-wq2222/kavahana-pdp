# Kavahana PDP mockups

Static mockups for the Kavahana Starter Kit subscription. No build step: each
page is a single self-contained HTML file. Edit the file, commit, and GitHub
Pages redeploys.

| Page | File |
| --- | --- |
| Starter Kit PDP (main deliverable) | `index.html` |
| Premium editorial PDP | `premium.html` |

**Not in this repo:** the subscription offer and unit-economics doc is kept out
deliberately, because it contains COGS, margins, CAC and price floors. It stays
as a private artifact.

## Notes

- Fonts and press logos are real files in `fonts/` and `press/`, referenced
  relatively, so the pages stay small and hand-editable.

- Every image is a labelled placeholder. The label describes the shot.
- Source files with build placeholders live in the working scratchpad; these
  are the built outputs.
- Copy rules: no em dashes, never name or knock competitors, never claim kava
  treats a condition, never say third party tested or that COAs are published,
  and "free" may only reference the add-ons, never the kit itself.

## Branding

Taken from the Kavahana brand book, with the section rhythm read off
shop.kavahana.com.

- Green `#367542`, secondary green `#73AE57`, off-white `#F8F3E8`, ink `#1F1D17`.
- Sections alternate white and off-white, with one full green band.
- Display headings: Newsreader 400 (light serif). Body: Chivo. `.mauna` is
  Mauna Loa, reserved for "Kava Nectar" and the occasional header.
- Newsreader is not in the brand book; it is the display face their live site
  already uses, and it is what makes the page read premium rather than
  generic DTC. Swap it out if the brand book wins.
